# smart-screen Tanıtım Sitesi — Uygulama Planı

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `gh-pages` tanıtım sitesini sıfırdan, iki dilli (TR/EN), dört ışık fazında renk değiştiren özgün bir sayfayla değiştirmek.

**Architecture:** `site/` altında tek kaynak (içerik + faz paleti + eğri matematiği), küçük bir Node üreteci `site/dist/` içine iki statik HTML yazar; `tools/site-check.mjs` bayat çıktıyı, dil eşliğini, kontrastı ve bütçeleri denetler; `tools/site-publish.mjs` yalnızca çıktıyı `gh-pages`'e iter.

**Tech Stack:** Node 22 ESM (bağımlılıksız), statik HTML/CSS, ~4 KB tarayıcı JS'i (`type="module"`), testler `node --test`, ekran görüntüleri için mevcut `qa/node_modules` playright (1.63.0).

**Spec:** [`docs/superpowers/specs/2026-11-19-site-design.md`](../specs/2026-11-19-site-design.md)

## Global Constraints

- Varlık yolları **göreli** (`./assets/...`); mutlak `/` yolu yasak (Pages alt yolda barınıyor).
- Dış istek yok: CDN, web font, izleyici, ikon paketi, harita. Ağ: 1 HTML + 1 CSS + 1 modül JS + görseller.
- Köke **yeni npm bağımlılığı eklenmez**. Playwright `qa/node_modules`'tan `createRequire` ile çözülür.
- Bütçeler: ilk yükleme (HTML+CSS+JS) ≤ 120 KB · tek kare ≤ 120 KB · tüm `site/dist` ≤ 900 KB · CSS ≤ 20 KB · JS toplam ≤ 5 KB.
- Kontrast: dört fazın **hepsinde** metin≥4.5, ikincil≥4.5, vurgu≥4.5, düğme metni≥4.5 (WCAG AA).
- Yasak görsel dil: blob/gradyan leke, cam + blur, mor/indigo vurgu, emoji ikon, üç kolonlu ikon-kart ızgarası, uydurma referans, stok fotoğraf.
- İçerik uydurulmaz: her sayı koddan gelir (`decide.rs`, `engine.ts`, `store.ts`, `license.rs`).
- Türkçe metin doğal Türkçe; EN metin çeviri değil, İngilizce yazılmış. Bölüm/SSS/bağlantı sayıları iki dilde eşit.
- Sır yok: araçlar token/anahtar okumaz. `.env` yok.
- Commit'ler `main`'e; yayın ayrı araçla `gh-pages`'e.
