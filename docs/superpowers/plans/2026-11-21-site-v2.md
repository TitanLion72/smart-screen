# Site v2 "Karanlık oda" — Uygulama Planı

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Tanıtım sitesini sıfırdan, "karanlık oda tek ışık" yönünde, 8 gerçek kare + 4 anlamlı hareketle yeniden yazmak.

**Architecture:** `site/v2/` altında yeni kaynak ağacı (içerik, şablon, CSS, JS); `tools/site2-build.mjs` iki dilde HTML üretir; `tools/site2-shots.mjs` 8 kareyi üretir; eski `site/` tasarımı yayından kaldırılır.

**Tech Stack:** Node 22 ESM, statik HTML/CSS, ~8 KB tarayıcı JS'i, self-hosted Bricolage (79.4 KB woff2), Playwright (qa/node_modules).

**Spec:** [`docs/superpowers/specs/2026-11-21-site-v2-design.md`](../specs/2026-11-21-site-v2-design.md)

## Global Constraints

- Varlık yolları göreli; mutlak `/` yasak (Pages alt yol).
- Dış istek yok: CDN, izleyici, ikon seti, stok foto yok. Font self-hosted.
- Köke npm bağımlılığı eklenmez; Playwright `createRequire(qa/package.json)` ile.
- **Yasak estetik (eski sitenin AI izleri):** ALL-CAPS eyebrow, mono veri etiketi,
  saç teli kural + gazete kolonu, krem+terracotta palet, `·` birleşik meta satırı,
  her bölümde fade-up.
- Renkler: void `#05070a` · wall `#0d1118` · text `#eeece7` · dim `#9aa0a8` ·
  glow `#ffbe86` · ember `#c2410c`. Metin kontrastı AAA (≥7).
- Bütçeler: font ≤85 KB · ilk yükleme ≤150 KB raw / ≤45 KB gzip · kare ≤120 KB ·
  JS ≤8 KB · tüm dist ≤900 KB.
- İçerik uydurulmaz; sayılar koddan (decide.rs, store.ts, engine.ts, license.rs).
- TR + EN, tek kaynak, yapısal parity zorunlu.
- Pro fiyatı yok.

## Review Focus

1. **JS kapalı:** tüm metin, 8 görsel ve indirme düğmesi görünür kalmalı. (Task 6)
2. **`prefers-reduced-motion`:** dört hareketin dördü de kapanmalı; içerik son hâlinde görünmeli (animasyonun başlangıç hâlinde donmamalı). (Task 5)
3. **360 px:** uzun EN kelimeler yatay kaydırma yaratmamalı. (Task 6)
4. **İlk boya:** sayfa koyu açılmalı (beyaz patlama yok); font yüklenmeden metin görünmeli (`font-display: swap`). (Task 5)
5. **Kare seçicisi koddan kalkarsa:** üretim gürültülü durmalı, boş görsel yayınlanmamalı. (Task 4)
